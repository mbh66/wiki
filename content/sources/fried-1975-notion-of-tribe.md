Fried, M. H. (1975). *The Notion of Tribe*. Cummings Modular Program in Anthropology. Cummings Publishing, Menlo Park, CA. 136 pp. ISBN 0-8465-1548-2.

Morton H. Fried, an anthropologist, questions the tribe as a stage between bands and states [TBV]. As [[sources/ronfeldt-2007-tribes-first-and-forever-form|Ronfeldt (2007)]] reports him, Fried accepts that states arose from uncentralised, kin-based villages, and holds that most groups called tribes formed later as secondary responses to intruding states [TBV]. Ronfeldt concedes that if this critique holds it would weaken the TIMN account of the tribal form [IC]. This entry rests on Ronfeldt's account, which is not independent of the work it defends; the book itself still has to be read [TBV].

The [[research/evolution-of-consciousness/library|library]] codes it as a critic work in anthropology, with evidence type E3 and claim code B3. It takes a position on one step, so it stays in the library outside the grid.
